# gote: Go/Wails → Rust/Tauri Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Go/Wails v3 backend with a Rust/Tauri v2 backend that reads and writes the existing on-disk note format byte-compatibly, and keep the vanilla-JS frontend with only its runtime/binding layer swapped.

**Architecture:** A Tauri v2 crate in `src-tauri/` holds the backend. Pure-Rust modules (`crypto`, `models`, `config`, `auth`, `note_store`, `image_store`, `backup`) carry all logic and are unit-tested with `cargo test`, with no Tauri dependency. `app.rs` is a plain-Rust facade (`AppCore`) that mirrors the Go `App` semantics. `commands.rs` holds thin `#[tauri::command]` wrappers over `AppCore`. The frontend keeps `main.js` as-is apart from its imports: a new `frontend/src/api.js` exports the same PascalCase function names the Wails bindings exported, implemented with `invoke`.

**Tech Stack:** Rust (edition 2024, toolchain 1.100), Tauri 2 (`tauri`, `tauri-build`, `tauri-plugin-clipboard-manager`, `tauri-plugin-opener`, `@tauri-apps/api`, `@tauri-apps/cli`), `aes-gcm`, `pbkdf2` + `sha2`, `base64`, `rand`, `serde`/`serde_json`, `chrono` (serde), `uuid` (v4), `regex`, `notify`, `zip`, `dirs`, `log` + `env_logger`, dev: `tempfile`. Frontend: Vite + bun (npm is not installed on the dev machine).

**Spec:** No separate spec. The behavioral reference is the Go source at commit `e5c6401` (`app.go`, `pkg/**`), read through the decisions in this plan. Golden fixtures generated by that Go code live in `testdata/go-fixtures/` (see Fixtures below).

## Global Constraints

- **On-disk compatibility is the top requirement.** A notes folder written by the Go app must open unchanged in the Rust app, and files the Rust app writes must stay readable by the Go app (users sync one folder across machines that may run different versions).
- Crypto: AES-256-GCM, 12-byte random nonce, stored as `base64(STD, padded)(nonce || ciphertext || 16-byte tag)`, no AAD. Key = PBKDF2-HMAC-SHA256(password, salt, 100_000 iterations, 32 bytes). Salt = 32 random bytes.
- Verification hash = base64(PBKDF2(password + "verification", salt)) (the literal suffix `verification`, same params).
- Local password file (default `~/.config/gote/password_hash`), compact JSON, mode 0600: `{"hash":"<b64>","salt":"<b64>"}`.
- Cross-platform config `<notesDir>/.gote_config.json`, pretty JSON (2-space), mode 0600: `{"salt":"<b64>","createdAt":"<RFC3339 local, seconds>","version":"1.0"}`.
- App config file `~/.config/gote/config` (no extension), pretty JSON: `{"notesPath": "...", "passwordHashPath": "..."}`. "Configured" means this file exists.
- Default notes dir `<home>/Documents/Gote/Notes` on **all** platforms, using `dirs::home_dir()`, not the platform documents dir. Created if missing.
- Note file `<notesDir>/<id>.json`, pretty JSON (2-space), mode 0644: `{"id","encrypted_data","created_at","updated_at"}`. Timestamps are RFC3339 with up to nanosecond precision and any offset on read; write them RFC3339 (chrono default serde is fine).
- Encrypted note payload = JSON `{"content": str, "category": str, "original_category"?: str, "images"?: [Image]}`. Omit `original_category` when empty and `images` when empty (Go `omitempty`). On read, if the decrypted text does not parse as a JSON **object**, it is a legacy note: the whole text is the content, category `private`. An empty or missing category reads as `private`.
- Image file `<notesDir>/images/<id>.json`, pretty JSON, mode 0644: `{"id","filename","content_type","size","encrypted_data","created_at"}`. Image bytes are encrypted directly (no base64 before encryption).
- IDs: 8 lowercase hex chars from the first 8 chars of a v4 UUID. Only files matching `^[0-9a-fA-F]{8}\.json$` in the notes dir root are notes. `.gote_config.json`, `corrupted/`, `backups/` and `images/` are never notes.
- **Every ID that reaches a filesystem path (note or image) must match `^[0-9a-fA-F]{8}$`; otherwise return the error `invalid id`.** (The Go code joined unchecked IDs into paths, which allowed path traversal via `image:../..` references.)
- Categories: `private`, `work`, `trash`.
- Sessions: 30-minute sliding timeout, in memory only. Expired-session cleanup every 5 minutes. The derived key lives only in memory, never on disk.
- The auth error string must contain `session expired` exactly: use `session expired - re-authentication required`. The frontend matches on that substring to auto-logout.
- Backups: `<notesDir>/backups/backup-<YYYYMMDD-HHMM>.zip` (local time). Every entry is prefixed `backup-<YYYYMMDD-HHMM>/`. Contents: each root-level `*.json` file once (this includes `.gote_config.json`) plus everything under `images/` recursively, at its path relative to notesDir with `/` separators. Never `backups/` or `corrupted/`. Replace an existing zip of the same name.
- Auto-backup: when configured, check at startup and then hourly. Back up if no `backup-*.zip` exists in `backups/` or the newest one's mtime is ≥ 24h old. Manual and scheduled backups go through one mutex.
- Window: title `gote`, 1200×1000, white background. Identifier `com.gote.app`, product name `gote`, version `1.7.0`.
- No frontend framework (CLAUDE.md convention). Keep `main.js` logic untouched beyond imports and the three runtime calls named in Task 7.
- Conventional-commit messages matching `^(feat|fix|chore|docs|refactor|test|perf|build|ci)(\([^)]+\))?: `.
- Frontend tooling is **bun** (`bun install`, `bun run build`); npm is not on the dev machine.
- Run the Tauri CLI from the repo root as `frontend/node_modules/.bin/tauri <cmd>`. `@tauri-apps/cli` is a devDependency of `frontend/package.json`.

## Review Focus

1. **Existing Go notes folder opened by Rust:** nanosecond timestamps with `+01:00` offsets, legacy payloads, empty categories, images. All must load, and the content must come back byte-identical. Pinned by the Task 2 and Task 4 fixture tests.
2. **Mixed-version sync:** a note the Rust app writes must parse with the Go field names and `omitempty` semantics. Pinned by `rust_written_note_has_go_shape` (Task 4).
3. **Second-machine bootstrap:** a synced folder with `.gote_config.json` and notes but no local hash file. The right password must log in and create the local hash; a wrong password must be rejected. The Go code checked a JSON key `encryptedData` that never exists, so this path always rejected; the Rust version must check `encrypted_data`. Pinned by `bootstrap_from_synced_folder_*` (Task 3).
4. **Cloud-sync file churn while the app runs:** external create/modify/delete of notes, the app's own writes not reprocessed, newest-`updated_at` wins, and non-note files ignored. Pinned by the Task 4 watcher tests.
5. **Logout or session expiry:** mutating commands fail with a `session expired` error, and after logout or expiry the note list commands return `[]`. The Go version kept serving decrypted notes from its cache after logout; Rust must clear the cache. Pinned by `logout_clears_notes` and `expired_session_rejects_mutation` (Task 6).

### Task 3: Auth manager

**Files:** Create `src-tauri/src/auth.rs`.

**Interfaces:**
- Consumes: `crypto::*`, `ids::is_note_filename`.
- Produces `AuthManager::new(password_hash_path: PathBuf, notes_dir: PathBuf)` and:
  - `is_first_time_setup(&self) -> bool`: true only if neither the local hash file nor `<notes>/.gote_config.json` exists.
  - `store_password_hash(&mut self, password) -> Result<()>`: if the cross-platform config exists and parses, reuse its salt and write only the local file. Otherwise generate a salt and write the local file, then the cross-platform config (a failure there is logged, not returned).
  - `verify_password(&mut self, password) -> bool`: (a) local file present and hash matches → true. (b) Otherwise, if the cross-platform salt loads: derive the key, scan root `*.json` files except `.gote_config.json`, and try to decrypt each one's **`encrypted_data`**. Any success → write the local hash file and return true. JSON files present but none decrypts → false. No JSON files but the config exists → write the local hash and return true. Sets `current_salt` along the way, like Go.
  - `derive_encryption_key(&mut self, password) -> Result<[u8;32]>`: use `current_salt` if set; else the cross-platform salt; else the local file's salt, writing the cross-platform config if it is missing. Error `no password set up` if neither exists.
  - `remove_password_hash(&self) -> Result<()>` (missing file is OK).
  - Sessions: `create_session(&mut self) -> String` (32 random bytes, URL-safe base64), `validate_session(&mut self, id) -> bool` (sliding 30 min; removes the session if expired), `delete_session(&mut self, id)`, `cleanup_expired(&mut self)`. The key is **not** stored in the session (AppCore holds it). Session timeout comes from a field `session_timeout: Duration` (default 30 min) so tests can shorten it.

### Task 4: Note store and file watcher

**Files:** Create `src-tauri/src/note_store.rs`.

**Interfaces:**
- Consumes: `models::*`, `crypto`, `ids`.
- Produces `NoteStore` (cheaply cloneable: the inner state sits in `Arc<RwLock<Inner>>` with `notes: HashMap<String, Note>`, `key: Option<[u8;32]>`, `mod_times: HashMap<PathBuf, SystemTime>`) with:
  - `NoteStore::new(data_dir: PathBuf) -> Result<Self>` (creates the dir)
  - `load_notes(&self, key: [u8;32]) -> Result<()>`: sets the key, starts the watcher once, runs `sync_from_disk`
  - `sync_from_disk(&self) -> Result<()>`: for each valid note file, decrypt it and keep it if it is new or has a newer `updated_at`; remove cached notes whose files are gone; record mtimes. Undecryptable or unparsable files are logged and skipped.
  - `clear(&self)`: drop the key and all cached notes (used on logout)
  - `create_note(&self, content: &str, category: Category) -> Result<Note>`; `update_note(id, content) -> Result<Note>`; `update_category(id, Category) -> Result<Note>`; `move_to_trash(id) -> Result<Note>` (keeps the original category unless already trash); `restore_from_trash(id) -> Result<Note>` (err `note is not in trash`; restores the original or `Private`, clears the original); `permanently_delete(id) -> Result<()>` (err `note must be in trash to be permanently deleted`); `get_note(id) -> Result<Note>` (err `note not found`); `all_notes() -> Vec<Note>`, `notes_by_category(Category)`, `search(query)` (case-insensitive substring on content). All lists are sorted by `updated_at` descending. `move_to_corrupted(id) -> Result<()>` → `<dir>/corrupted/<id>.json`.
  - Every write updates `updated_at = Utc::now()`, saves `<id>.json` and records its mtime. Mutations without a key → `AppError` `not authenticated`. Every id goes through `ensure_valid_id`.
  - Watcher: a `notify::RecommendedWatcher` (non-recursive) on the data dir, with events handled on its own thread. Ignore paths that fail `is_note_filename`. Create/Modify → if the mtime is newer than the recorded one, re-read, decrypt and replace when newer (`updated_at`). Remove, or a rename whose path no longer exists → drop it from the cache. Never panic in the watcher thread.

### Task 6: AppCore facade, Tauri commands, app wiring
